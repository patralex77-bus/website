.env Beispiel

Trage diese Werte in deine lokale .env Datei oder später in Render Environment Variables ein. 

EMAIL_NOTIFICATIONS_ENABLED=true
PUBLIC_BASE_URL=http://127.0.0.1:5000

NOTIFICATION_TO=office@austria-express.eu
MAIL_FROM=office@austria-express.eu
MAIL_FROM_NAME=Austria Express Website

SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USERNAME=your-smtp-username
SMTP_PASSWORD=your-smtp-password
SMTP_USE_TLS=true
SMTP_USE_SSL=false
SendGrid SMTP: SMTP Host meistens smtp.sendgrid.net, Username meistens apikey, Password ist der API Key.
Mailgun SMTP: SMTP Host und Credentials kommen aus deinem Mailgun Domain Dashboard.
Normales Postfach: SMTP Daten des E-Mail Providers verwenden.

Was wird automatisch gesendet?

Neue Kontaktanfrage

Wenn jemand das Kontaktformular sendet, wird die Anfrage gespeichert und zusätzlich eine E-Mail an office@austria-express.eu gesendet.

Neue Bus Rental Anfrage

Wenn jemand das Bus Rental Formular sendet, wird die Anfrage gespeichert und zusätzlich eine E-Mail an office@austria-express.eu gesendet.
